# The-Achiver

The Achievers Institute of Learning — website + student portal (`theachievers.com.np`).
Frontend: React + Vite + TypeScript (`frontend/`). Backend: Django + DRF (`backend/`).

## Run

```bash
ollama serve
cd backend && pip install -r requirements.txt && python manage.py migrate && python manage.py runserver 0.0.0.0:8000
cd frontend && npm install && npm run dev   # http://localhost:5173
```

## AI MCQ Test Lab (Mock Test page)

Interactive 100-question MCQ test (25 each: Mathematics, Physics, Chemistry, English),
generated by the local `qwen2.5:3b` model through Ollama. Open **Mock Test** in the navbar.

Config (`backend/.env.example`): `OLLAMA_URL` (default `http://localhost:11434`),
`OLLAMA_MODEL` (default `qwen2.5:3b`), `MOCKLAB_PASS_MARK` (default `0.4`),
`MOCKLAB_DEFAULT_MINUTES` (default `100`).

How it works: tests build up in rounds of 5 (20 rounds = 100). Each round generates
5 questions for the next unfinished subject (topics rotated), validated (4 distinct
options, valid key, no duplicates across all previous tests) and independently
re-solved by the model — mismatches are discarded and retried (max 3 per slot).
Correct-option positions are randomized. Solve a round, submit it for an instant
score plus AI explanations, then hit Next for 5 more. Answers autosave per question;
the timer (default 100 min) auto-submits. Final scoring is deterministic code; the AI
then writes per-question explanations (reusing round feedback, no repeat cost) and an
overall summary, falling back to stored text if any AI call fails.

## Troubleshooting

- **Ollama not reachable / model missing**: run `ollama serve`, then
  `ollama pull qwen2.5:3b`. The backend prints this fix on startup and the Mock Test
  page shows it. Health: `GET /api/v1/mocklab/health/`.
- **Generation failed / stalled**: the 3B model is flaky — the status screen shows the
  reason; just generate a new set.
- **Database is locked**: background AI jobs share dev SQLite; `timeout: 30` is set.
  Restart the backend if a job is killed mid-write.
- **Stale "generating" after a server restart**: status calls auto-mark it failed with
  a retry message — nothing gets stuck.
- **Port in use**: frontend `npm run dev -- --port 5174 --host`; backend
  `python manage.py runserver 0.0.0.0:8001` (update `VITE_API_BASE_URL` + CORS).
